# Mika (mobile) — мобильная версия голосового ассистента

> Мобильная (Android) версия дипломного проекта **Mika** — системы управления умным домом
> с офлайн-распознаванием речи. Специальность 09.02.07, 2025 г.

Версия для смартфона на **Kivy**. Повторяет ядро настольной версии (распознавание речи,
логика команд, работа с умными устройствами через API) и добавляет взаимодействие
с телефоном (управление устройством, сервер между ПК и телефоном).

## Возможности
- Голосовое управление умным домом (Vosk, офлайн).
- Свет: вкл/выкл, цвета, яркость.
- Управление телефоном (`phone_control.py`) и связь с ПК через `app_mobile/phone_server.py`.
- Модульная система команд (тот же паттерн `Command`, что и в настольной версии).

## Технологии
Python 3, **Kivy**, Vosk, PyAudio, requests. GUI описан в `styles.qss`-подобных ресурсах
и Kivy-виджетах.

## Структура
```
Mika_main.py          # ядро ассистента
Mika_UI.py            # интерфейс на Kivy
command_handler.py    # маршрутизация команд
commands/             # команды (light_control, music_mode, phone_control, ...)
app_mobile/           # серверная часть для связи с телефоном
fotos/, images/       # графика
```

## Запуск
```bash
pip install -r requirements.txt
# положить модель vosk-model-small-ru-0.22 в корень
python Mika_main.py
```
